# Data-Integrity Checklist

- [ ] Raw data preserved read-only with hashes
- [ ] Metadata schema valid and acquisition commit present
- [ ] Synthetic, simulation, and measurement labels correct
- [ ] Processed outputs reference raw inputs and code
- [ ] Exclusions retained with reasons
- [ ] Figures reproducible and no manual appearance edits
- [ ] No personal, clinical, identifiable, restricted, or oversized Git data
