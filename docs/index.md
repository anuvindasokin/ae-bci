# AE-BCI Documentation

AE-BCI is a frequency-flexible laboratory research platform for controlled
acoustoelectric heterodyne experiments. Start with the [project scope](project-scope.md),
[system architecture](architecture/system-architecture.md), and
[phantom-only restriction](safety/phantom-only-restriction.md).

> [!CAUTION]
> Repository generation and passing software tests do not validate hardware, the
> acoustoelectric mechanism, biological performance, or medical safety.
