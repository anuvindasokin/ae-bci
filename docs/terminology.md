# Terminology

- **Acoustic carrier (`fA`)**: selected ultrasound frequency in hertz.
- **Electrical source (`fE`)**: controlled neural-equivalent waveform frequency.
- **Sidebands**: components at `fA − fE` and `fA + fE`.
- **Candidate AE response**: a control-qualified observation, not proof by itself.
- **Configuration**: a carrier-specific calibrated hardware and settings record.
- **Measured / simulated / proposed**: distinct evidence states; never interchangeable.
