# Carrier Sidebands

For carrier `fA` and source `fE`, the lower sideband is `fA − fE` and the upper is
`fA + fE`. Software calculates these dynamically. Examples include 492 kHz and
508 kHz for a 500 kHz carrier with an 8 kHz source, and 992 kHz and 1.008 MHz for
a 1 MHz carrier. Sidebands alone do not establish an acoustic interaction.
