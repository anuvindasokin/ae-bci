# Signal Model

The observed carrier-band voltage is modelled as the sum of candidate AE content,
direct RF pickup, source leakage, nonlinear mixing, mechanical/microphonic pickup,
ground interference, lock-in offset, and noise. Signed recovery is
`(X − X0) cos(θ) + (Y − Y0) sin(θ)`, with offsets from ultrasound-only data and
phase `θ` from calibration.
