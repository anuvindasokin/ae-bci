# Lock-In Amplifier

The instrument should exceed 1 MHz with headroom and support external coherent
reference, dual-phase X/Y streaming, filter/order control, stable phase, overload
and range status, and preferably raw diagnostics. Record X, Y, R, phase, reference,
time constant, ENBW, order, rate, range, and overload. Model is `TBD`.

Broadband recovery provisionally needs ≥10 kHz output bandwidth and ≥25 kS/s X/Y
(40–50 kS/s preferred). Narrowband settings are engineering starting points and
must be derived from the actual instrument filter definition and waveform.
